# data/ 폴더 안내

이 폴더에 공공데이터포털에서 내려받은 CSV 파일을 그대로 넣으면 `app.py`가 자동으로 인식합니다.

## 인식 가능한 컬럼 (순서 무관, 이름으로 매핑)

- 위도: `WGS84위도`, `위도`, `lat`, `latitude` 중 하나
- 경도: `WGS84경도`, `경도`, `lon`, `longitude` 중 하나
- 주소(선택): `소재지도로명주소`, `소재지번주소`, `도로명주소`, `주소`, `address` 중 하나

컬럼명이 정확히 일치하지 않아도 위 후보 문자열이 포함되어 있으면 자동으로 매핑됩니다.
(예: 안심귀갓길 데이터처럼 `경도` 컬럼이 `위도`보다 앞에 있어도 문제없습니다.)

## 카테고리 자동 분류 기준 (파일명 기준)

| 파일명에 포함된 키워드 | 분류되는 레이어 |
| --- | --- |
| `cctv` | CCTV |
| `가로등`, `보안등`, `led` | 가로등 |
| `비상벨`, `긴급벨` | 비상벨 |
| `안심귀갓길`, `안심i` | 안심귀갓길 |
| `안전시설물` | 안전시설물 |
| `범죄`, `crime`, `치안` | 범죄위험 |
| (위 키워드 없음) | 기타 |

예: `서울특별시_CCTV표준데이터.csv`, `서울특별시_보안등정보.csv`,
`서울특별시_안전비상벨설치현황.csv`, `서울특별시_안심귀갓길현황.csv`

## 지원하지 않는 파일 형태 (자동으로 건너뜀 + 경고 표시)

- **위도/경도 컬럼이 없는 파일**: 주소만 있는 파일(예: 일부 비상벨 데이터)은 좌표 컬럼을 찾지 못하면
  자동으로 스킵되고 사이드바에 경고가 표시됩니다. 지도에 표시하려면 별도로 지오코딩(주소→좌표 변환)한
  CSV로 가공한 뒤 넣어주세요.
- **자치구별 범죄 통계 같은 집계(피벗) 테이블**: `자치구별(1)/자치구별(2)` + `발생/검거` 형태의
  2단 헤더 통계표는 점(포인트) 데이터가 아니라 행정구역 단위 집계라서 이 지도에서는 다루지 않습니다.
  이런 데이터는 추후 자치구 경계 GeoJSON과 결합한 코로플레스(choropleth) 지도가 필요하며,
  현재의 '골목길 vs 격자' 판단용 포인트 밀도 지도와는 목적이 다릅니다.

## 인코딩

`utf-8-sig`, `cp949`, `euc-kr` 순서로 자동 감지하여 읽으므로 공공데이터포털에서 받은 원본 그대로 넣으면 됩니다.
