# 귀가ON (Comeback-on)

[AI 지니어스 아카데미]

> 1인 가구 및 치안 취약계층을 위한 **AI 기반 안전 보행 경로 안내 서비스**
> 공공 안전시설 데이터를 확인하며 보행 경로를 비교하고, 동의한 보호자에게 귀가 상황을 공유하는 프로젝트입니다. 데이터가 있다는 것만으로 실제 안전을 보장하지 않습니다.

## 모바일 웹 실행

와이어프레임의 남색·노란색 디자인과 하단 5개 메뉴를 실제 웹으로 연결했습니다. 기본 실행 화면은 `webapp.py`이며, 아래의 기존 Streamlit 분석 화면도 별도로 실행할 수 있습니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m flask --app webapp run --port 8501
```

브라우저에서 `http://localhost:8501`을 엽니다. Windows에서는 `.venv\Scripts\Activate.ps1`로 가상환경을 활성화합니다. 휴대폰의 실제 위치 사용에는 HTTPS가 필요합니다.

### 연결된 흐름과 남은 외부 설정

| 기능 | 현재 동작 |
|---|---|
| 비회원 홈·검색·경로 비교·귀가 안내 | 목적지 검색과 보행 경로는 서버의 TMAP API를 사용합니다. 키가 없으면 연결 필요 상태를 표시합니다. |
| 이메일 회원가입·로그인 | 해시한 비밀번호, 서버 인증, 계정별 저장 장소·설정, 회원 탈퇴를 지원합니다. |
| 안전 시설 | 저장소의 실제 공공데이터 CSV를 읽어 주변 시설과 거리를 표시합니다. |
| 보호자 연결 | 회원 이메일로 요청하고 상대가 수락해야 연결됩니다. 연결만으로 위치가 공유되지는 않습니다. |
| 위치 공유 | 귀가 시작 시 동의하면 연결된 보호자가 최신 위치와 선택한 경로를 볼 수 있습니다. 이전 위치를 누적하지 않으며 공유 중단·귀가 종료 시 좌표를 지웁니다. |
| 보호자 알림 | 서비스 내 알림 기록을 제공합니다. 문자 발송은 연결되지 않았으며 문자 전송 완료로 표시하지 않습니다. |
| 긴급 도움 | 112 전화·문자 앱 연결, 보호자 SOS 3초 취소 흐름. 실제 112 발송은 휴대폰에서 사용자가 완료합니다. |
| 제보 | 글·위치·사진 등록, 내 제보, 미확인 표시, 계정별 ‘저도 확인했어요’ 토글. 사진은 검증 후 재인코딩하여 위치 메타데이터를 제거합니다. |
| 최단·안심 경로 | TMAP 최단·대로우선 후보 2개에 구간별 소요 시간과 주변 등록 시설 가중치를 적용해 비교합니다. 우회 범위와 근거를 만족하는 별도 후보가 있을 때만 안심 대안을 표시합니다. 검증된 보행 도로망 파일을 연결하면 해당 도로망에서 다익스트라로 탐색합니다. |
| 전화번호·간편 로그인 | 화면에 연동 필요 상태를 표시합니다. 문자 인증, 카카오·네이버·Apple 인증은 아직 연결하지 않았습니다. |
| AI 설명 | 현재 설명은 확보한 시설 자료에서 만든 근거 문장입니다. 별도 생성형 AI는 연결하지 않았습니다. |
| 이탈·지연 자동 감지 | 거리·시간·응답 대기 기준이 확정되지 않아 자동 감지와 자동 문자 전송은 활성화하지 않았습니다. |
| 쌍방 위치·흔들기·반복 진동 | 아직 구현하지 않았습니다. 현재 위치 공유는 귀가자에서 보호자로 향하는 일방 공유입니다. |

### 맥에서 TMap 키 한 번만 등록하기

프로젝트 폴더의 `setup-tmap.command`를 열면 맥 입력창이 나옵니다. TMap 키를 붙여넣고 저장하세요. 터미널에서는 `open ./setup-tmap.command`로 열 수 있습니다. 실행 중인 앱은 다시 시작합니다.

등록 도구는 키를 `instance/tmap_app_key`에 본인만 읽고 쓸 수 있는 권한으로 저장합니다. 이 파일과 임시 키 파일은 Git·Docker에 포함하지 않으며, 키를 채팅·브라우저·터미널 출력에 표시하지 않습니다. 로컬 저장 키가 있으면 이전 터미널 환경 변수보다 우선 사용하므로 창을 새로 열어도 유지됩니다. 저장 완료는 API 인증 성공을 뜻하지 않으며, 실제 장소 검색으로 별도 확인해야 합니다.

### 실행 환경 변수

`.env.example`은 값의 예시이며 자동으로 읽지 않습니다. 실행 셸 또는 배포 서비스의 Environment 메뉴에 등록합니다. 실제 값이 들어간 `.env` 파일은 커밋하지 않습니다.

- `TMAP_APP_KEY`: 로컬 등록 파일이 없는 경우 사용할 TMAP 키. 브라우저에 전달하지 않고 서버에서만 사용합니다. 보행 경로와 장소 검색(POI) 상품 권한이 모두 필요합니다. 배포 서버에는 이 환경 변수로 등록합니다.
- `COMEBACK_SECRET_KEY`: 배포 환경에서 사용하는 충분히 긴 무작위 세션 비밀 값.
- `COMEBACK_DATA_DIR`: SQLite DB·제보 사진 저장 위치. 기본 `instance/`.
- `COMEBACK_COOKIE_SECURE=1`: HTTPS 배포 시 사용합니다. HTTP localhost 개발에서는 `0`.
- `ROUTING_GRAPH_FILE`: 검증한 실제 보행 도로망 GeoJSON 경로. 없으면 TMAP 후보 2개 안에서 비교하며, 전체 도로망의 최적 경로라고 표시하지 않습니다. 계단 피하기를 켜면 계단 제외가 보장되지 않은 대로우선 후보는 비교하지 않습니다.

데이터 없는 곳에 임의의 위험 페널티를 주지 않습니다. ‘안심’은 선택한 데이터와 가중치에 따른 비교이며 범죄 확률이 아닙니다. 우회 기본값은 소요 시간 증가 30%와 추가 20분을 **둘 다** 만족하는 범위입니다.

현재 입력 범위는 개발용으로 증가율 0~100%, 추가 시간 0~60분으로 제한했습니다. 팀의 최종 기준이 확정되면 조정합니다. TMAP 후보 비교는 요청마다 최단 경로 1회와 대로우선 경로 최대 1회를 호출하므로 제공량·요금은 서비스 콘솔에서 확인합니다. 실제 기기·API 키를 통한 검증은 별도로 필요합니다.

도로망 파일은 `FeatureCollection` 형식이며, 각 보행 가능한 `LineString`에 `from`, `to`, `walkable: true`를 넣습니다. 좌표는 GeoJSON 표준의 `[경도, 위도]`입니다. 같은 교차점 ID만 연결하며 교량·지하도 교차를 임의로 연결하지 않습니다. `stairs`, `oneway`, 확인된 주의 정보의 `verified_attention`, `attention_reason`, `attention_penalty_s`를 지원합니다. 원본과 연결성을 검증한 도로 데이터에만 사용합니다. 세부 계약은 `routing.py` 상단에 있습니다.

### 배포 및 검증

Docker와 `render.yaml`의 기본 실행을 모바일 웹으로 변경했습니다. 건강 확인 주소는 `/health`입니다. 기존 Render 서비스는 `main` 자동 배포 설정과 Environment 변수를 확인하세요. 이 변경 자체가 실제 서비스 재배포 완료를 보장하지는 않습니다.

**현재 Render free 설정은 로컬 저장소가 영구적이지 않습니다.** 재시작·재배포 때 계정·제보가 초기화될 수 있습니다. 지속 운영 전 영구 볼륨 또는 별도 데이터베이스로 이전해야 하며, 이 저장소 변경으로 유료 플랜을 신청하지 않습니다. 위치 갱신은 웹 화면이 실행 중일 때 작동하며 화면 잠금·백그라운드 지속 추적은 보장하지 않습니다.

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
node --check mobile/app.js
```

## 기존 안전 인프라 데이터 분석 화면

지도 분석 단위를 **골목길(Link) 단위**로 할지 **격자(Grid) 단위**로 할지 판단하기 위해,
공공데이터의 위경도 좌표 분포와 밀도를 한눈에 확인하는 웹 지도(`app.py`)입니다.

### 주요 기능

- Folium + Streamlit 기반 인터랙티브 지도
- 주소 입력 시 해당 위치로 지도 이동 및 마커 표시 (geopy/Nominatim)
- **검색 위치 안전 리포트**: 지도 옆 패널에 분석 반경(100~1000m, 사이드바 슬라이더) 안의 CCTV·가로등·비상벨·안전시설물 개수, 가장 가까운 시설까지 거리, 서울 평균 대비 비율, 해당 자치구의 범죄 발생 건수·서울 내 비중(%)·순위·검거율·면적당 범죄 밀도·반경 내 추정 범죄 건수, 범죄 유형별 비중 표시 (마커 팝업에도 요약)
- CCTV·가로등·비상벨·안심귀갓길·범죄위험 레이어를 지도 우측 상단 체크박스로 On/Off (`LayerControl`)
- 안전 인프라 밀도 확인용 Heatmap 레이어
- `MarkerCluster`로 대용량 포인트도 가볍게 렌더링
- 사이드바에서 현재 지도를 `.html` 파일로 저장 → 브라우저로 바로 열람 가능
- 컬럼명이 데이터셋마다 달라도(`WGS84위도`/`위도`, `소재지도로명주소`/`소재지번주소` 등) 자동 매핑
- 좌표가 없는 주소 전용 데이터, 자치구별 집계 통계표처럼 이 지도에 맞지 않는 파일은 자동으로 건너뛰고 경고 표시

## 폴더 구조

```
Comeback-on/
├── app.py              # 메인 Streamlit 앱
├── requirements.txt    # 의존 라이브러리 목록
├── data/                # 공공데이터 CSV 저장 위치 (data/README.md 참고)
└── README.md
```

## 실행 방법

### 1. 가상환경 생성 및 활성화

```bash
python -m venv venv

# Windows (PowerShell)
venv\Scripts\Activate.ps1

# macOS / Linux
source venv/bin/activate
```

### 2. 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 3. 데이터 준비

공공데이터포털에서 받은 CSV(CCTV, 보안등, 비상벨, 안심귀갓길, 범죄 관련 등)를 `data/` 폴더에 넣습니다.
컬럼명 매핑 규칙, 카테고리 자동 분류 기준, 지원하지 않는 데이터 형태는 [data/README.md](data/README.md)를 참고하세요.

### 4. 앱 실행

```bash
streamlit run app.py
```

브라우저가 자동으로 열리며 지도가 표시됩니다. 사이드바의 "현재 지도를 HTML로 저장" 버튼을 누르면
`output_map.html` 파일이 생성되어 Streamlit 없이도 브라우저에서 바로 열어볼 수 있습니다.
